# Task API

## Description
A CRUD API built using Node.js and Express.

## Installation

npm install

## Run

node server.js

## Base URL

http://localhost:3000

## Endpoints

| Method | Endpoint |
|--------|----------|
| GET | /health |
| GET | /tasks |
| GET | /tasks/:id |
| POST | /tasks |
| PUT | /tasks/:id |
| DELETE | /tasks/:id |

## Swagger

http://localhost:3000/docs
